# Yandex Algorithms Intensive Solutions

## Описание проекта

Репозиторий содержит решения алгоритмических задач, выполненных в рамках интенсива по алгоритмам.

В проекте представлены решения **21 задачи на Python**, направленные на развитие навыков алгоритмического мышления, работы со структурами данных и оптимизации решений.

## Используемые технологии

- Python 3
- Алгоритмы и структуры данных
- Работа со строками
- Графы
- Деревья
- Оптимизация вычислений

## Темы задач

В рамках интенсива были реализованы задачи по следующим направлениям:

- обработка массивов и последовательностей;
- работа со строками;
- алгоритмы поиска;
- структуры данных;
- графовые алгоритмы;
- деревья;
- моделирование процессов;
- вычислительные задачи.
